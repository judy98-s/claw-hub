# 외부 API 키 발급 가이드

캐릭터 트렌드 기능에 필요한 키 두 개다. **둘 다 무료**이고, 사장님 명의로
신청해야 한다 — 내가 대신 만들 수 없다.

먼저 신청해두면 승인 기다리는 동안 다른 작업을 할 수 있다.

| | 승인 시간 | 난이도 |
|---|---|---|
| 네이버 데이터랩 | **즉시** | 쉬움 |
| KOBIS (영화진흥위원회) | **즉시~당일** | 쉬움 |
| 공공데이터포털 (선택) | 3시간~3일 | 보통 |

---

## 1. 네이버 데이터랩 — 검색어 트렌드 (즉시)

"쿠로미가 지난주보다 얼마나 더 검색됐나"를 알려준다. 캐릭터 트렌드의 핵심이다.

1. <https://developers.naver.com> 접속 → 네이버 계정으로 로그인
2. 상단 **Application → 애플리케이션 등록**
3. 입력:
   - **애플리케이션 이름**: `claw-hub` (아무거나 괜찮다)
   - **사용 API**: **`데이터랩 (검색어 트렌드)`** 체크
     - 같은 화면에서 **`데이터랩 (쇼핑인사이트)`** 도 같이 체크해두면 좋다.
       나중에 따로 신청할 필요가 없다.
   - **환경 추가**: `WEB 설정` 선택 → 서비스 URL 에 도메인 입력
     (아직 도메인이 없으면 `http://localhost` 로 두고 나중에 고쳐도 된다)
4. 등록하면 바로 **Client ID** 와 **Client Secret** 이 나온다

**나에게 전달할 것 — 채팅에 붙여넣지 말 것.** 아래 §4 참고.

```
NAVER_CLIENT_ID=...
NAVER_CLIENT_SECRET=...
```

> **한도:** 검색어 트렌드·쇼핑인사이트 각각 **월 5만 건**. 캐릭터 100개를
> 하루 한 번 도는 데 하루 20건이면 충분하니 한도의 1.2% 만 쓴다.

## 2. KOBIS — 영화 개봉 정보 (즉시~당일)

"다음 달에 포켓몬 극장판이 개봉한다"를 알려준다. **개봉 2~4주 전에 알면
사입할 시간이 있어서**, 트렌드 신호 중에 제일 값어치가 있다.

1. <https://www.kobis.or.kr/kobisopenapi/homepg/apiservice/searchServiceInfo.do> 접속
2. 우측 상단 **회원가입** → 가입 후 로그인
3. **키 발급/관리** 메뉴에서 **인증키 발급** 신청
4. 발급되면 즉시 쓸 수 있다

```
KOBIS_API_KEY=...
```

> 검색으로 확인한 바로는 발급 신청 후 즉시 사용 가능하다고 되어 있다.
> 다만 이 작업 환경에서 kobis.or.kr 이 네트워크 정책에 막혀 있어 페이지를
> 직접 열어보지 못했다. 화면이 위 설명과 다르면 알려달라 — 맞춰서 고치겠다.

---

## 3. 공공데이터포털 — 사업자등록 상태조회 (선택, 3시간~3일)

지금은 **안 해도 된다.** 장터의 사업자등록번호는 체크섬으로 검증하고 있고,
그걸로 오타와 아무 숫자는 걸러진다.

나중에 "이 번호가 진짜 살아 있는 사업자인가"까지 확인하고 싶어지면 그때 한다.
폐업한 사업자가 장터에 글을 쓰는 걸 막고 싶을 때다.

1. <https://www.data.go.kr/data/15081808/openapi.do> 접속 → 회원가입
2. 우측 상단 **활용신청** → 사용 목적 기입
3. 승인까지 3시간~3일. 승인되면 인증키가 나온다

```
NTS_API_KEY=...
```

## 4. 키를 나한테 주는 방법

**채팅창에 그대로 붙여넣지 마세요.** 대화 기록에 남고, 나중에 이 기록을 보는
사람도 볼 수 있습니다.

권장 순서:

1. 서버의 `.env` 파일에 직접 적으신다
   ```bash
   echo 'NAVER_CLIENT_ID=...'     >> .env
   echo 'NAVER_CLIENT_SECRET=...' >> .env
   echo 'KOBIS_API_KEY=...'       >> .env
   ```
2. 나한테는 **"키 넣었다"** 고만 알려주시면 된다
3. 나는 `.env` 를 읽지 않고, 코드가 그 이름으로 읽도록만 만든다

만약 키가 안 먹어서 디버깅이 필요하면, **키 자체 말고 에러 메시지**를
보여주시면 된다.

> 예전에 Slack 웹훅 URL 을 채팅에 붙여넣으신 적이 있다. 그건 지금도 유효한
> 상태이니 한 번 재발급해두시는 게 좋다 — Slack 앱 설정에서 기존 웹훅을
> 지우고 새로 만들면 된다.

---

## 신청 후

키가 다 나오면 알려달라. 그때 캐릭터 트렌드를 붙인다. 순서는:

1. 감시할 캐릭터 목록 만들기 (50~100개 — 산리오·포켓몬·짱구·디즈니·최근 애니)
2. 매일 도는 워커가 네 신호를 긁어 저장
3. "이번 주 눈여겨볼 캐릭터" 화면

키가 없어도 **1번은 지금 할 수 있다.** 목록이 먼저 있어야 나머지가 의미가 있다.
