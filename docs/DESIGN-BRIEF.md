# 디자인 브리프

디자이너에게 맡기거나, AI 도구에 넣거나, 나중에 내가 다시 볼 때 쓰는 설명서다.
**그대로 복사해서 건네도 된다.**

---

## 1. 한 줄

무인매장(인형뽑기·코인노래방·무인세탁)에서 기계가 돈만 먹었을 때,
**손님이 QR 로 직접 환불을 접수하고 사장님이 알림으로 승인하는** 서비스.

## 2. 화면은 세 종류고, 셋의 요구가 다르다 ← 가장 중요

이걸 구분하지 않고 "사이트를 예쁘게" 라고 하면 반드시 어긋난다.
세 면은 보는 사람도, 상황도, 목표도 다르다.

| | 랜딩 `/` | 손님 폼 `/r/{code}` | 사장님 대시보드 `/admin` |
|---|---|---|---|
| 보는 사람 | 처음 보는 사장님 | 지금 돈을 잃은 손님 | 매일 쓰는 사장님 |
| 상황 | 책상·출퇴근길 | 고장난 기계 앞, 한 손, 지하 LTE | 퇴근 후 침대, 햇빛 아래 |
| 목표 | 붙잡기 | **끝까지 작성시키기** | 빠르게 판단하기 |
| 쓰는 횟수 | 1번 | 평생 1~2번 | 하루 수십 번 |
| 화려함 | 허용 | **금지** | 금지 |
| 밀도 | 낮게 | 낮게 | **높게** |

- **랜딩만 트렌디해도 된다.** 파는 면이니까.
- **손님 폼은 화려하면 안 된다.** 계좌번호를 입력하는 화면이다.
  애니메이션과 장식은 "이거 사기 아냐?" 를 만든다. 신뢰가 전환율이다.
- **대시보드는 빽빽해야 한다.** 여백이 많으면 스크롤이 늘고,
  스크롤이 늘면 사장님이 안 본다.

## 3. 사용자 둘

**손님** — 20~30대. 방금 1,000원을 잃었고 짜증이 나 있다. 지하 매장이라
신호가 나쁘다. 한 손으로 조작한다. 앱을 깔 생각이 없다.
→ 입력 칸을 줄이고, 글자를 키우고, 다음에 뭘 할지 한 번에 하나만 보여준다.

**사장님** — 비기술 자영업자, 40~50대가 많다. 매장에 없을 때 민원을 받는다.
낮에는 햇빛 아래에서 폰을 본다.
→ 대비를 높이고(4.5:1 이상), 용어 대신 그 사람 말을 쓴다
  ("클레임" 아니고 "민원", "트랜잭션" 아니고 "건").

## 4. 제약

- **모바일 우선.** 손님은 100% 폰, 사장님도 대부분 폰.
- **한글이 1순위.** `word-break: keep-all` 이 없으면 "붙이고" 가
  "붙 / 이고" 로 갈라진다. 본문 폰트는 Pretendard.
- **돈·계좌·전화번호를 다룬다.** 화려함이 신뢰를 깎는 영역이다.
- **접근성.** 확대를 막지 않는다(사장님이 증상 사진을 키워 본다).
  대비 4.5:1 이상.
- 가벼워야 한다. 지하에서 손님 폼이 먼저 죽으면 접수 자체가 안 된다.

## 5. 지금 쓰는 색과 역할

| 토큰 | 역할 |
|---|---|
| `ink-*` | 바탕과 글자. 중립 회색이 아니라 **살짝 따뜻한** 회색 |
| `accent-*` (짙은 청록) | **행동** — 버튼·링크·포커스 링 |
| `rose-*` (분홍) | **장식** — 배경면·마스코트·강조. 누를 수 있는 것에는 안 쓴다 |
| `ok / warn / stop` | 상태 3종. 전부 배경 대비 4.5:1 이상 |

장식과 행동을 나누는 게 핵심이다. 분홍 바탕에 분홍 버튼을 놓으면
누를 곳이 어디인지 사라진다.

**마스코트 「뽑이」** — 집게에 집히지 못한 분홍 토끼.
표정 4종(calm·happy·worried·sleep)이고 **귀로 감정을 말한다**
(기쁘면 서고, 걱정이면 처진다). 22px 까지 읽힌다.

## 6. 하지 말 것 (안티-디폴트)

AI 도구와 템플릿이 기본으로 뱉는 것들이다. 전부 금지한다.

- 보라 그라데이션
- 다크 메시 히어로
- **3개 균등 카드** (순서가 있는 흐름을 균등 카드로 놓으면 "셋 중 아무거나" 가 된다)
- 전면 글래스모피즘
- Inter + slate-900 조합
- 인디고 / 바이올렛 / blue-600 액센트
- 손님 폼의 애니메이션
- 특정 IP(산리오·나가노 등) 캐릭터를 닮은 그림 — 상용 서비스라 분쟁이 된다

## 7. 피드백은 이렇게 준다

"구리다 / 빈티난다" 는 정보가 없어서 추측으로 다시 그리게 된다.
아래 축 중 **어느 것이 문제인지** 짚으면 한 번에 수렴한다.

| 축 | 한쪽 | 반대쪽 |
|---|---|---|
| 밀도 | 빽빽하다 | 휑하다 |
| 대비 | 너무 세다 | 흐리다 |
| 색 수 | 알록달록하다 | 단조롭다 |
| 곡률 | 너무 둥글다(유치) | 너무 각졌다(딱딱) |
| 선 굵기 | 굵다(귀엽다) | 가늘다(세련됐다) |
| 여백 | 답답하다 | 떠 있다 |
| 글자 크기 | 크다(초보용) | 작다(전문가용) |
| 톤 | 유치하다 | 차갑다 |

**예시**
- ✗ "이 캐릭터 구려" → ✓ "선이 너무 굵어서 유치해 보여. 색도 채도가 높아"
- ✗ "홈페이지 이상해" → ✓ "히어로가 휑하고 제목이 작아서 빈약해 보여"
- ✗ "더 트렌디하게" → ✓ "요소가 많아서 정리가 안 돼 보여. 줄여줘"

**레퍼런스를 줄 때**는 링크만 주지 말고 *무엇이* 좋은지 한 줄 붙인다.
"이거처럼" 은 색을 말하는지 여백을 말하는지 알 수 없다.
